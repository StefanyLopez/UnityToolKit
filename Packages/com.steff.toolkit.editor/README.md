# Steff's Unity Toolkit - Editor

Modular Unity Editor tools for streamlining project setup and development workflows.

## Requirements

- Unity 6 (6000.0 or newer within the 6000.x release family).

## Installation (local development)

Add this package to a Unity project's `Packages/manifest.json`:

```json
{
  "dependencies": {
    "com.steff.toolkit.editor": "file:../../SteffsUnityToolkit/Packages/com.steff.toolkit.editor"
  }
}
```

Adjust the relative path to match the location of your repository.

## Included

- Steff's Toolkit overview window.

## Open the window

In Unity, select **Window > Steff's Toolkit > Overview**.
